# 茶茶捕捉 Flex 制作器使用说明

这份说明介绍“Flex 制作”工具。它用于给某一个模型制作独立的：

```text
ARKit / MediaPipe 通道 -> 模型 Flex
```

制作完成后，玩家面捕可以直接使用这个预设；也可以在制作器里不启动摄像头，先用静态滑杆检查模型效果。

## 一、打开制作器

1. 启动 Garry's Mod，并确认控制台出现“茶茶捕捉已加载”。
2. 按 `Q` 打开出生菜单。
3. 找到工具枪分类：`工具 -> 茶茶捕捉 -> Flex 制作`。
4. 选择工具枪后，在左侧面板点击“打开 Flex 映射制作器”。

也可以在控制台输入：

```text
facetracker_flex_creator
```

如果菜单里没有这个工具，先完全退出并重启游戏，检查插件目录是否为：

```text
garrysmod/addons/face-tracker/lua/
```

不要多套一层 `face-tracker/face-tracker`。

## 二、选择要制作的模型

窗口最上方的下拉框是目标模型。它可能显示：

- 玩家本体
- PAC3 模型
- NPC
- 布娃娃

模型必须有 Flex，否则不会出现在列表中。

选择目标后，左侧会列出模型全部 Flex。点击“刷新目标/Flex”可以重新扫描，例如刚刚刷新了 PAC3 或刚生成了布娃娃时使用。

目标模型切换后，当前编辑内容会切换到新模型；建议先保存当前模型，再切换目标。

## 三、调整静态 Flex

左侧每一行是一个模型 Flex：

- 名称：模型实际的 Flex 名称。
- “静态值”滑杆：直接给这个 Flex 一个固定值。
- 搜索框：按名称筛选 Flex，例如输入 `blink` 或 `mouth`。

静态值适合测试模型的表情，或者制作一个始终保持的基础表情。它的范围通常是 `0` 到 `2`。

注意：如果同一个 Flex 同时配置了实时映射，运行时会使用：

```text
静态值 + 实时映射值
```

结果最后限制在 `0` 到 `2`。

## 四、添加 ARKit / MediaPipe 映射

窗口底部是映射编辑区，按以下顺序操作：

1. 第一个下拉框选择目标 Flex。
2. 第二个下拉框选择输入通道，例如 `jawOpen`、`eyeBlinkLeft`、`mouthSmileLeft`。
3. 调整“权重”。正数表示同方向驱动，负数表示反方向驱动。
4. 调整“倍率”。它会把通道输出再乘一次，用于放大或减弱效果。
5. 调整“阈值”。输入低于这个值时按 `0` 处理，可过滤轻微抖动。
6. 需要反向时勾选“反向”。
7. 点击“添加映射”。

一个 Flex 可以添加多条通道。例如：

```text
mouth_smile <- mouthSmileLeft x 0.50
mouth_smile <- mouthSmileRight x 0.50
```

这样左右嘴角会共同驱动同一个模型 Flex。

### 编辑和删除映射

右侧“已添加映射”列表会显示当前所有映射：

- 单击一行：把它载入底部编辑区，修改后点击“修改映射”。
- 双击一行：删除这一条映射。

删除后如果需要重新添加，重新选择 Flex、通道和参数，再点击“添加映射”即可。

## 五、实时预览

制作器会在窗口打开期间持续运行预览：

- 如果 Python 面捕已经运行，通道数值变化会直接驱动目标模型。
- 如果没有启动摄像头，静态 Flex 仍然可以预览。
- 目标实体被删除、模型失效或 PAC3 重载后，预览会自动停止；点击“刷新目标/Flex”重新选择。

如果实时效果不明显，先把权重或倍率调到 `1.00` 左右，再检查选择的通道是否确实有数据。

## 六、保存模型专属预设

1. 在顶部文本框输入预设名称，例如：

```text
my_model_face
```

2. 点击“导出表情预设”。
3. 文件会保存到：

```text
garrysmod/data/facetracker/presets/my_model_face.txt
```

名称不要输入 `.txt`，插件会自动添加扩展名。建议使用英文、数字、下划线和短横线。

保存内容包含模型路径、静态 Flex、映射明细，以及播放器兼容的 `expressions` 表达式。

## 七、加载已有模型预设

1. 先在顶部选择目标模型。
2. 点击“加载模型预设”。
3. 插件会在 `data/facetracker/presets/` 中查找模型路径完全相同的预设。
4. 找到后会恢复静态值和映射列表。

如果提示“没有找到该模型的专属预设”，常见原因是：

- 预设是给另一个模型制作的；
- 模型路径发生了变化；
- 文件没有放在 `garrysmod/data/facetracker/presets/`；
- 文件不是有效 JSON。

## 八、在玩家面捕中使用

1. 关闭制作器或保留窗口打开均可。
2. 启动 `server/start_player_tracker.bat`。
3. 在 GMod 的玩家面捕面板中，把“面部预设”填写为保存文件名，不要写 `.txt`：

```text
my_model_face
```

4. 点击“启动玩家捕捉”。

也可以在控制台输入：

```text
facetracker_player_preset my_model_face
facetracker_player_start
```

使用 `auto` 时，插件会自动扫描自定义预设，并优先选择和当前模型匹配度最高的预设。

## 九、推荐的起步参数

第一次制作时可以使用下面的参数：

| 项目 | 建议值 |
| --- | ---: |
| 权重 | `0.50` 到 `1.00` |
| 倍率 | `1.00` |
| 阈值 | `0.03` 到 `0.10` |
| 反向 | 默认关闭 |

先只添加一条映射并观察效果，确认方向正确后，再逐条增加其他通道。

## 十、常见问题

### 找不到模型

模型没有 Flex，或者实体还没有生成完成。确认 NPC、布娃娃或 PAC3 部件已经出现，然后点击“刷新目标/Flex”。

### 预览完全不动

确认 Python 面捕程序已启动，并且 GMod 已连接。可以先用左侧静态值滑杆验证模型本身是否能改变。

### 表情方向反了

编辑对应映射，勾选“反向”，或把权重改成负数。眼睛左右反向时，分别检查 `eyeLook...Left` 和 `eyeLook...Right` 通道。

### 保存后加载不到

检查文件是否在：

```text
garrysmod/data/facetracker/presets/
```

并确认当前模型的路径和制作预设时完全一致。

### 关闭窗口后仍然影响模型

正常关闭会清理预览 Think hook。如果模型仍保持最后一个静态值，重新打开制作器选择同一模型，并点击“清空当前表情”；必要时重新生成实体。

